# Monis Kumar Das — Handcrafted Personal Portfolio

A fast, bespoke, and responsive personal portfolio website built with pure **Semantic HTML5, Modern CSS3 (Variables & Glassmorphism), and Vanilla JavaScript**.

Designed specifically for **Monis Kumar Das**, 2nd-year B.Tech CSE (AI & ML) student at **Lovely Professional University**.

---

## 🌟 Key Highlights & Craftsmanship

- **Pure Web Stack**: 100% Vanilla HTML5, CSS3, and JavaScript — Zero external build dependencies, instant load times.
- **Human-Crafted Aesthetic**: Slate obsidian dark mode with electric cyan & indigo ambient lighting, modern typography (Space Grotesk + Plus Jakarta Sans + JetBrains Mono), smooth micro-interactions.
- **Interactive Lightbox Modal**: Click any certificate (Saylor C++, WNS CyberSmart, Tech Veda Time Management, NeoColab Top 30 & CSE101) to preview high-resolution images or PDFs directly in the browser.
- **Interactive Developer Terminal ("Monis CLI")**: Functional mini-console allowing visitors to run commands (`bio`, `skills`, `projects`, `education`, `certs`, `socials`, `contact`, `clear`).
- **Live Dark/Light Mode Switcher**: Seamless theme transition with `localStorage` persistence.
- **Interactive Skills Filter**: Filter between All, Programming Languages, Web & Frontend, Databases & Tools, and Soft Skills.
- **One-Click Email & Contact Copy**: Instant clipboard copying with sleek toast notifications.
- **Accessible & Mobile Responsive**: Mobile drawer navigation, semantic tags, and ARIA labels.

## 🚀 How to Run

### Option 1: Using `npm run dev`
```bash
npm run dev
```
This automatically starts the local server and opens `http://localhost:3000` in your default browser.

### Option 2: Direct Open
Double-click [`index.html`](file:///c:/Users/Monis/Desktop/portfolio%203/index.html) in your file explorer to open it in any web browser without running any terminal commands.
